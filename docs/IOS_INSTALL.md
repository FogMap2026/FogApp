## 0. 먼저 읽어야 할 것 — 안드로이드처럼 간단하지 않습니다

안드로이드는 링크 하나로 끝납니다. **iOS는 그렇게 안 됩니다.**

| | Android | iOS |
|---|---|---|
| 설치 | 링크 → 끝 | `.ipa` 받아 → **각자 PC에서 서명** → 케이블로 설치 |
| 준비물 | 없음 | Windows PC + 케이블 + Apple ID + 도구 설치 |
| 유효기간 | 무제한 | **7일** |
| 폰당 개수 | 무제한 | 3개 |
| 푸시 알림 | 됨 | **안 됨** |

**왜 이런가** — 애플은 서명되지 않은 앱의 실행을 막습니다. 서명하려면 Apple Developer Program(**$99/년**)이 필요한데, 우리는 그걸 안 쓰기로 했습니다. 대신 **무료 Apple ID로 본인 폰에만 서명해서 넣는** 우회로를 씁니다. 그 대가가 위 표의 제약입니다.

> ⚠️ **7일 제약을 가볍게 보지 마세요.** 시연 당일에 앱이 안 열리는 사고가 여기서 납니다.
> **시연 전날 반드시 다시 설치하세요.**

## 1. 준비물

| | |
|---|---|
| **Windows PC** | 관리자 권한 필요 |
| **아이폰 + 케이블** | 무선으로는 안 됩니다 |
| **Apple ID** | 무료 계정으로 충분합니다. 유료 개발자 계정 불필요 |
| **Sideloadly** | https://sideloadly.io — 무료 |
| **iTunes · iCloud** | **Apple 공식 사이트에서** 받으세요 (아래 주의) |

> ⚠️ **Microsoft Store 버전 iTunes는 동작하지 않습니다.** Sideloadly가 필요로 하는 드라이버가
> 스토어 버전에는 들어 있지 않습니다. https://www.apple.com/itunes/ 에서 받은 설치 파일을 쓰세요.

### 🔐 Apple ID 는 별도 계정을 권합니다

Sideloadly에 Apple ID와 비밀번호를 입력하게 됩니다. 도구가 애플 서버로 직접 보내는 구조이긴 하지만, **평소 쓰는 계정 대신 이 용도로만 쓸 계정을 새로 만드는 편이 안전합니다.** 결제 수단을 등록하지 않아도 무료 계정은 만들어집니다.

> ⚠️ **2단계 인증이 켜진 계정이면 앱 암호(app-specific password)가 필요합니다.**
> https://account.apple.com 로그인 → 로그인 및 보안 → 앱 암호 → 생성.
> 일반 비밀번호를 넣으면 계속 실패합니다. 원인 메시지가 불친절해서 여기서 많이 막힙니다.

## 2. `.ipa` 받기

**PC 브라우저에서 이 주소를 여세요.** (약 20MB)

```
https://desktop-i6a90dk.taild500a1.ts.net/fogapp.ipa
```

압축을 풀 필요 없이 그대로 3장으로 넘어가면 됩니다.

> ⚠️ **폰이 아니라 PC로 받으세요.** 아이폰에서 받아봐야 서명이 안 돼 있어 설치할 수 없습니다.
> 서명은 PC의 Sideloadly가 합니다.

<summary>링크가 안 열릴 때 — GitHub에서 직접 받기</summary>

이 주소는 인프라 담당자의 PC에서 서비스됩니다. PC가 꺼져 있으면 안 열립니다.

> 아티팩트가 안 보이면 그 실행에서 iOS 잡이 건너뛰어진 것입니다 — 앱 코드가 안 바뀐 커밋이면
> 그렇게 됩니다. 인프라 담당에게 요청하면 코드 변경 없이 다시 구울 수 있습니다.
> ```
> gh workflow run ci.yml --repo FogMap2026/FogApp --ref dev
> ```

> 를 열면 바로 설치됩니다. 서명도 PC도 필요 없습니다.

## 3. 서명하고 설치하기

1. **아이폰을 케이블로 연결**하고, 폰에 뜨는 **"이 컴퓨터를 신뢰하시겠습니까?"** 에서 **신뢰**를 누릅니다
2. **Sideloadly 실행**
3. 창에 **`FogApp-unsigned.ipa` 를 끌어다 놓습니다**
4. **Apple ID** 입력 (2단계 인증 계정이면 **앱 암호**)
5. **`Start`** 클릭
6. 비밀번호를 묻는 창이 뜨면 입력하고 기다립니다 (수 분 걸릴 수 있습니다)

### 설치 직후 — 이 단계를 빠뜨리면 앱이 안 열립니다

폰에 아이콘은 생겼는데 누르면 **"신뢰할 수 없는 개발자"** 라고 뜹니다. 다음을 해야 열립니다.

**설정 → 일반 → VPN 및 기기 관리 → (본인 Apple ID) → 신뢰**

## 4. 서버 주소 — 앱이 서버를 못 찾으면 여기부터

`.ipa`에는 **빌드 시점의 서버 주소가 구워져 있습니다.** 현재 값:

```
https://desktop-i6a90dk.taild500a1.ts.net
```

살아 있는지 확인:

```
https://desktop-i6a90dk.taild500a1.ts.net/api/health
```

`{"status":"UP"}` 이 보이면 정상입니다.

> ⚠️ **이 서버는 인프라 담당자의 PC에서 돌아갑니다.** PC가 꺼져 있으면 앱이 로그인부터 실패합니다.
> 브라우저에서 위 주소가 안 열리면 앱 문제가 아니라 서버가 내려간 것입니다 — 담당자에게 알려주세요.
>
> 주소가 바뀌면 `.ipa`를 **다시 구워야 합니다.** 앱 안에서 바꿀 수 없습니다.

## 5. 안 될 때

| 증상 | 원인과 조치 |
|---|---|
| Sideloadly가 폰을 못 찾음 | Microsoft Store 버전 iTunes를 지우고 **Apple 사이트 버전**으로 다시 설치. 케이블을 바꿔 보세요(충전 전용 케이블은 데이터가 안 통합니다) |
| 로그인이 계속 실패 | 2단계 인증 계정입니다. **앱 암호**를 만들어 쓰세요 (1장 참고) |
| `Provisioning profile` 관련 오류 | 무료 계정은 **주당 앱 ID 10개** 제한이 있습니다. 여러 번 재시도했다면 걸린 것이니 **다음 주까지 기다리거나 다른 Apple ID**를 쓰세요 |
| 설치는 됐는데 아이콘 누르면 닫힘 | 3장의 **신뢰** 단계를 안 했습니다 |
| 며칠 뒤 갑자기 안 열림 | **7일이 지났습니다.** 2~3장을 다시 하세요 — 정상 동작입니다 |
| 앱은 뜨는데 로그인·지도가 안 됨 | 4장 — 서버가 내려갔는지 먼저 확인 |
| 푸시 알림이 안 옴 | **무료 계정에서는 안 됩니다.** 고장이 아닙니다 |

## 6. 이 방식으로 안 되는 것

**심사위원이 링크만 받아 설치하는 것은 불가능합니다.** 애플 정책이라 우회가 없습니다.

| 방법 | 필요한 것 | 심사 |
|---|---|---|
| **TestFlight** | Apple Developer **$99/년** | 외부 테스터는 1~2일 |
| **Ad Hoc + OTA 설치** | Apple Developer **$99/년** + 기기 UDID 사전 등록 | 없음 |

> 📌 **어느 쪽이든 유료 계정이 전제입니다.** 대회가 "심사위원이 각자 폰에 설치해 본다" 형식이면
> $99 결제 판단이 필요합니다. 우리가 폰으로 시연하는 형식이면 이 문서의 방식으로 충분합니다.
> — **PM 확인 필요 사항입니다.**

Ad Hoc + OTA 설치는 우리 서버가 이미 유효한 HTTPS를 갖고 있어(Tailscale Funnel) 유료 계정만 생기면
`itms-services://` 링크로 바로 붙일 수 있습니다. 계정이 준비되면 인프라 담당이 구성합니다.

## 7. iOS에서 확인해줬으면 하는 것

CI가 시뮬레이터로 앱 실행과 화면 렌더링까지 자동 확인합니다. **하지만 시뮬레이터로 못 잡는 것이 있습니다** — 실기기에서 이 셋을 봐주세요.

1. **카메라** — 스팟 인증 사진 촬영. 시뮬레이터에는 카메라가 없어 아예 검증이 안 됩니다
2. **GPS 정확도** — 발자취 남기기가 *"위치가 정확하지 않아요"* 로 자주 막히는지.
   현재 **정확도 10m 이하**일 때만 허용합니다([#118](https://github.com/FogMap2026/FogApp/issues/118)).
   실내나 건물 사이에서 계속 막히면 임계값을 올려야 합니다
3. **권한 팝업 문구** — 카메라·위치·모션 세 가지가 한국어로 제대로 뜨는지

이상한 점은 이슈로 올려주세요. 🟧 INF로 넘어올 것이면 [@songkh1201](https://github.com/songkh1201) 을 걸어주세요.
