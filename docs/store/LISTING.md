# 원스토어 등록 문구

[docs/ONESTORE_RELEASE.md](../ONESTORE_RELEASE.md) 3장의 빈칸을 채운 것입니다. 등록 화면에 **그대로 복사해 넣으면 됩니다.**

이미지는 [docs/store/](.) 를 보세요.

## 상품 제목

```
FogApp - 안개 지도 탐험
```

> 스토어에 따라 제목 길이 제한이 있습니다. 잘리면 `FogApp` 만 남겨도 브랜드는 전달됩니다.

## 한줄 설명

```
발로 뛰어 안개를 걷어내는 탐험형 여행 지도
```

## 상품 설명

```
🌫️ 대한민국 전체가 안개로 덮여 있습니다.

FogApp은 화면만 보는 여행 앱이 아닙니다. 실제로 그 장소에 도착해야 안개가
걷히고, 그 자리에 무엇이 있었는지 비로소 드러납니다.

■ 걸어서 밝히는 지도
지도는 회색 안개로 시작합니다. 관광 스팟은 안개 아래 숨어 있어 가까이 가기
전에는 무엇인지 알 수 없습니다. 스팟 100m 안에 들어가면 알림이 오고, 현장에서
사진을 찍어 인증하면 그 일대의 안개가 걷힙니다.

■ 지역을 정복하는 재미
안개를 걷어낼 때마다 시/군/구 단위 정복률이 올라갑니다. "경주 15%" 처럼
숫자로 보이기 때문에, 한 번 더 걸어볼 이유가 생깁니다.

■ 길 위에 남는 글귀
지나간 자리에 짧은 글을 남길 수 있습니다. 앞서 걸어간 여행자의 글귀가 지도
위에 떠 있어, 걷다가 발견해 읽게 됩니다. 남길 수 있는 횟수는 정해져 있고
스팟을 정복하면 다시 채워집니다 - 더 쓰고 싶으면 더 걸어야 합니다.

■ 여행 성향이 맞는 동행
즉흥형인지 계획형인지, 휴양인지 관광인지를 묻는 성향 테스트를 마치면 비슷한
성향의 여행자를 추천받고 동행을 요청할 수 있습니다.

■ 한국관광공사 공식 관광정보
전국 관광 스팟의 명칭·주소·소개 정보를 한국관광공사 OpenAPI로 받아옵니다.

─────────────────────────

[필요한 권한]
· 위치(필수) - 안개를 걷을 위치를 판정하고 주변 스팟을 찾는 데 씁니다.
  위치 정보는 방문 인증과 발자취를 남긴 지점을 기록하는 데만 쓰입니다.
· 카메라(선택) - 방문 인증 사진 촬영에만 씁니다.

[알아두실 점]
이 앱은 실제 이동을 전제로 합니다. 실내이거나 관광 스팟에서 멀리 떨어져 있으면
인증할 대상이 없어 지도가 비어 보일 수 있습니다.
```

> ⚠️ **등록 직전에 확인할 것**: "한국관광공사 공식 관광정보" 문구는 데이터 출처 표기이지
> 제휴·인증을 뜻하지 않습니다. 스토어 심사에서 오해될 여지가 있으면 **"한국관광공사
> OpenAPI 기반"** 으로 바꾸세요.

> 으로 바꾸세요.

## 카메라 권한 - 문서와 실제가 다릅니다

[ONESTORE_RELEASE.md](../ONESTORE_RELEASE.md) 는 *"위치·카메라 권한을 쓰므로"* 라고 적고 있지만,
`AndroidManifest.xml` 에 **선언된 권한은 위치 둘뿐입니다.**

```
android.permission.ACCESS_FINE_LOCATION
android.permission.ACCESS_COARSE_LOCATION
```

`image_picker` 가 **시스템 카메라 앱을 호출**하는 방식이라 `CAMERA` 권한 선언이 필요 없습니다.
정상 동작이며 권한을 추가할 이유가 없습니다 — 다만 **스토어 권한 안내에 카메라를 "필수"
로 적으면 실제와 어긋납니다.** 위 설명 문구에는 "선택" 으로 적었습니다.
