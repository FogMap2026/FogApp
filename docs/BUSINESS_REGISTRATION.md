# 🧾 사업자등록 신청 가이드 (위치기반서비스사업 신고 선행)

> 담당: 송건희 [@songkh1201](https://github.com/songkh1201) (인프라)
> 관련: [#151](../../issues/151) 위치정보 신고 · [docs/ONESTORE_RELEASE.md](ONESTORE_RELEASE.md) 1-2 절
> 조사 기준일: 2026-09-09

> ⚠️ **세무·법률 자문이 아닙니다.** 국세청·홈택스 안내와 업종코드 자료를 우리 상황에 대입한 것입니다.
> **접수 전에 세무서에 확인받는 것을 권합니다** — 방문하면 그 자리에서 봐줍니다.

---

## 0. 왜 사업자등록이 필요한가

원스토어 등록에 **위치기반서비스사업 신고**가 걸려 있고([ONESTORE_RELEASE.md](ONESTORE_RELEASE.md) 1-2 절), 그 신고 경로가 사업자등록을 전제로 합니다.

| 신고 경로 | 사업자등록 |
|---|---|
| **소상공인등 특례** — 신고 없이 개시, 1개월 후 신고 | **전제** (소상공인·1인창조기업은 사업자등록이 요건) |
| **일반 신고** — 처리 약 5~6일 | 구비서류에 *"사업자 현황·사업 내용이 포함된 사업계획서"* 가 있습니다 |

**즉 어느 쪽으로 가도 사업자 신분이 필요합니다.**

> 📌 사업자등록 → 위치기반서비스사업 신고 **순서입니다.** 신고를 먼저 하려 해도 사업자 정보를 요구합니다.

---

## 1. 신청 경로 — 홈택스를 권합니다

```
홈택스 → 국세증명·사업자등록·세금관련 신청/신고 → 사업자등록 신청(개인)
```

| | 홈택스 | 세무서 방문 |
|---|---|---|
| 준비물 | 공동인증서 | 신분증 + 신청서(자필 서명) |
| 처리 | **2영업일** | 3일 |
| 수수료 | 없음 | 없음 |
| 접수 시간 | **평일 09~18시만** (주말·공휴일 불가) | 평일 업무시간 |

**아래 값은 두 경로에 공통입니다.** 종이 양식(「사업자등록 신청서(개인사업자용)」 별지 제4호서식)의 칸 이름을 기준으로 적습니다.

> 📌 신청 기한은 **사업 개시일로부터 20일 이내**입니다. 개시 전에도 등록할 수 있습니다.

---

## 2. 인적사항

| 칸 | 값 |
|---|---|
| **상호(단체명)** | `FogApp` — 자유. 나중에 변경 가능합니다 |
| 성명(대표자) · 주민등록번호 | 대표자 본인 |
| **사업장(단체) 소재지** | **자택 주소로 가능합니다.** 고정 사업장이 없으면 주소·거소를 사업장으로 할 수 있습니다. 층·호까지 |
| 사업장 전화번호 | 없으면 휴대전화번호와 같게 |
| FAX 번호 | 공란 |

## 3. 사업장 현황 — 여기가 핵심입니다

### 업종

| 칸 | 값 |
|---|---|
| **주업태** | **정보통신업** |
| **주종목** | **응용 소프트웨어 개발 및 공급업** |
| 주생산요소 | **공란** — 제조업에서 쓰는 항목입니다 |
| **주업종 코드** | **`722000`** |
| **개업일** | 아래 참고 |
| 종업원 수 | `0` |
| 부업태 · 부종목 · 부생산요소 · 부업종 코드 | **공란** |

**`722000`(응용 소프트웨어 개발 및 공급업)** 이 앱 개발의 표준 코드입니다. 표준산업분류 `58222` 에 대응하고, 국세청 분류 설명에 *"모바일용 응용 소프트웨어를 개발·공급하는 산업활동"* 이 포함돼 있습니다.

> 🔴 **개업일이 위치기반서비스사업 신고와 얽힙니다.** 신고서에 사업 개시일을 적는데, **개업일이 신고일보다
> 앞서야** 앞뒤가 맞습니다. 신청일 당일로 두면 무난합니다.

### 나머지 칸

| 칸 | 값 | 이유 |
|---|---|---|
| 사이버몰 명칭 · 도메인 | **공란** | 우리가 운영하는 쇼핑몰이 아닙니다. 원스토어는 남의 스토어입니다 |
| 사업장 구분 | 자택이 본인 소유면 **자가**, 아니면 **타가** | |
| 임대차 명세 | 무상 사용이면 **공란** | 대신 **무상사용승낙서**를 요구할 수 있습니다 |
| **허가 등 사업 여부** | **`해당 없음`** | 아래 별도 설명 |
| 개별소비세 해당 여부 | **전부 공란** | 제조·판매·입장·유흥 해당 없음 |
| 사업자금 명세 | 자기자금 `0`(또는 소액), 타인자금 `0` | |
| 사업자 단위 과세 적용 신고 여부 | **`부`** | 사업장이 하나입니다 |
| **간이과세 적용 신고 여부** | **`여`** | 아래 별도 설명 |
| 전자우편주소 | 대표자 메일. **SMS·전자우편 수신 동의 체크 권장** | 세무서 안내를 놓치지 않습니다 |
| 확정일자 / 공동사업자 / 사업장 외 송달장소 | **전부 `부`** | |
| 양도자 사업자등록번호 | **공란** | 사업을 인수한 것이 아닙니다 |

> 💡 **공동사업자를 `부` 로 두는 이유** — 팀이 5인이지만 **단독 개인사업자가 절차상 훨씬 간단합니다.**
> 공동사업자로 하면 전원의 인적사항·지분이 들어가고, 이후 신고·세무도 함께 얽힙니다. 대회 출품에
> 필요한 것은 "신고 주체가 되는 사업자" 하나입니다.

## 4. 헷갈리는 칸 둘

### 「허가 등 사업 여부」 → `해당 없음`

이 칸은 **음식점·학원처럼 사업자등록 전에 인허가가 필요한 업종**을 위한 것입니다. 소프트웨어 개발업은 해당하지 않습니다.

**위치기반서비스사업 신고는 순서가 반대입니다** — 사업자등록을 먼저 하고 그 사업자로 신고합니다. 여기에 「신고」를 체크하고 신고필증을 첨부하려 하면 오히려 막힙니다.

> ⚠️ 확신이 필요하면 접수 전에 세무서에 물어보세요.
> *"앱 개발업으로 등록한 뒤 위치기반서비스사업 신고를 할 예정인데, 허가등 사업 여부를 어떻게 적나요"*

### 「간이과세 적용 신고 여부」 → `여`

| | 간이과세 | 일반과세 |
|---|---|---|
| 적용 기준 | **연매출 1억 400만원 미만** | 초과 시 전환 |
| 세율 | 낮음 | |
| 세금계산서 발행 | 제약 있음 | 가능 |
| 매입세액 공제 | 제약 있음 | 가능 |

**무료 앱이라 매출이 없고, 소프트웨어 개발업은 간이과세 배제업종이 아닙니다.** 간이과세가 유리합니다.

일반과세가 나은 경우는 **거래처가 세금계산서를 요구할 때**인데, 우리는 해당하지 않습니다.

## 5. 🔴 신청 전에 알아야 할 것

**① 사업자등록은 세금 신고 의무를 만듭니다.**
매출이 0이어도 **부가세 신고**(간이과세자는 연 1회, 1월)와 **종합소득세 신고**(5월)를 해야 합니다.
무실적이면 "무실적 신고"로 금방 끝나지만, **안 하면 가산세**가 붙습니다.

**② 건강보험 피부양자 자격을 확인하세요.**
부모님 건강보험에 피부양자로 들어 있다면 영향이 있을 수 있습니다. 사업자등록이 있어도 **사업소득이 0이면 자격이 유지될 수 있고**, 2026년 탈락 기준은 연소득 2,000만원 초과입니다. 무료 앱이라 소득이 없을 가능성이 높지만, **확실히 하려면 건강보험공단(☎ 1577-1000)에 확인**하세요.

**③ 대회가 끝나면 폐업 신고**도 해야 합니다. 안 하면 신고 의무가 계속 남습니다.

## 6. 위치기반서비스사업 신고로 이어지는 부분

신고 구비서류 ②가 **「사업용 주요설비의 내용 및 설치 장소」** 인데, **우리 주요설비는 서버**입니다.

```
사업장 소재지  = 자택           (사업자등록)
주요설비 위치  = 네이버 클라우드 (국내 리전)
```

**둘이 다릅니다.** 클라우드를 쓰는 경우 이걸 어떻게 적는지는 표준 답을 찾지 못했습니다 —
**위치정보지원센터(☎ 02-588-0185) 문의 때 함께 확인하세요.**

> ✅ 서버를 이미 **국내 클라우드로 옮겨 뒀습니다**([#154](../../issues/154)). 팀원 PC 주소로 신고했다가
> 나중에 옮기면 변경신고를 해야 했는데, 그 문제는 사라졌습니다.
